# Справочник достижений The Binding of Isaac: Repentance

Статический сайт-справочник по достижениям игры **The Binding of Isaac: Repentance**.  
Позволяет просматривать достижения по персонажам и по дополнениям, фильтровать их и читать подробные условия получения.


## 🎮 Возможности

### Слайдер персонажей
- Горизонтальный слайдер с 17 персонажами игры.
- Переключение между **обычными** и **альтернативными** (Tainted) версиями персонажей по кнопке-иконке в заголовке секции.
- Клик по иконке на свитке открывает модальное окно с подробной информацией о достижении.

### Сетка достижений
- Все достижения сгруппированы по дополнениям:
  - **Rebirth** (id 1–178)
  - **Afterbirth** (id 179–276)
  - **Afterbirth+** (id 277–403)
  - **Repentance** (id 404–641)
- Клик по карточке открывает модальное окно с описанием и условиями получения.

### Фильтры
- Кнопка **«Сбросить фильтр»** — показывает все достижения.
- Фильтры по категориям: **«Персонажи»**, **«Разное»**.
- Аккордеон **«Боссы»** с вложенными фильтрами: «Мама», «Сердце Матери», «Босс-раш».
- Фильтры можно **комбинировать** между собой (мультивыбор).
- Повторный клик по фильтру снимает его.

### Модальное окно
- Отображает изображение, название, категорию, описание и условия получения достижения.

## 🚀 Установка и запуск

Проект полностью статический — сборка не требуется.

1. Склонируйте репозиторий или скачайте файлы.
2. Убедитесь, что папка `images/` содержит все необходимые изображения.
3. Откройте `index.html` в браузере.


## 🔍 Фильтрация достижений

- Фильтры хранятся в массиве `currentFilters`.
- Каждое достижение имеет поле `cat`, которое сравнивается с выбранными фильтрами.
- Чтобы добавить новый фильтр, добавьте кнопку с атрибутом `data-filter="ИмяКатегории"` в `index.html` — логика подхватит её автоматически (класс `boss-filter-btn`).
